Plan a drive and see the estimated boost forecast at stops along the way, timed to when you'd actually arrive.

Routing via OSRM's public demo server (best-effort, rate-limited — not for heavy use). Arrival times are estimates based on average driving pace, not live traffic.

Each selection tries two free, keyless forecast APIs live from your browser, in order: the National Weather Service (plain-text conditions) then Open-Meteo (numeric WMO weather codes) — watch the badge above the tabs to see which one answered, or whether it fell back to the simulated model. City search uses Open-Meteo Geocoding; ZIP search chains Zippopotam.us → Nominatim (OpenStreetMap) → an offline regional approximation, so it resolves to something even if one API is temporarily unreachable.

Pokémon GO's actual in-game weather comes from a private, authenticated Niantic service that this app has no access to. What you see here is a best-effort forecast from public weather data (matching what Niantic's source, AccuWeather, would likely show), so it can occasionally diverge from what's actually boosted in the app for a given hour.
